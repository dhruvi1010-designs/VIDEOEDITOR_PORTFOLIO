## 🚀 How to Publish on GitHub Pages (Free Hosting)

1. Go to [github.com/new](https://github.com/new) and create a repository named `portfolio`.
2. Upload all files from `e:\MY NEW portfolio` into that repository.
3. In repository **Settings** -> **Pages**, choose branch `main` and root `/`, then click **Save**.
4. Your website will be live at:
   👉 **`https://dhruvi1010-designs.github.io/portfolio/`**
